# T04 — «They Advertised $146. The Checkout Said $649.» (They Saw You Coming, ролик 4)
Тему дал Павел 19.11.2026 (проверку волны пропускаем по его решению). Повод: иск FTC + Юта + Невада против Lens.com, 02.10.2026.

Правило подачи: иск FTC — обвинения, суд не решал, ответственность не установлена. Ответа Lens.com на этот иск в открытых источниках не нашли; в групповых исках 2024 г. позиция компании — сбор раскрыт до оформления, разумный покупатель заметит изменение суммы. Слова «fraud/scam» не используем. Скриншоты — из иска (Fig. 1–20), подписывать «Source: FTC v. Lens.com complaint». Сотрудники поддержки — не мишень. Самуркачяна не высмеиваем — только факты из иска.

## Наши расчёты (подпись «our calculation»)
- 146.32 + 273.44 + 9.95 = 429.71 (сходится с иском до цента).
- $45.79 × 8 = $366.32 = Subtotal; $220 / 8 = $27.50 ребейт на коробку; 45.79 − 27.50 = 18.29 — рекламная цена = обычная цена минус ребейт.
- Сбор на коробку: 273.44 / 8 = $34.18 — почти вдвое больше рекламной цены коробки (34.18 / 18.29 = 1.87).
- После ребейта, без доставки: (146.32 + 273.44) / 8 = $52.47 за коробку — в 2,87 раза больше $18.29.
- Сбор / подытог: 273.44 / 366.32 = 74,6 % («about three quarters»).
- $649.71 / ($146.32 + $9.95) = 4,16 (иск: «more than four times»).
